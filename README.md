## 📖 Overview

This project showcases a premium web development standard with a strong focus on aesthetics and seamless user experience (UX). The core of this project is its **Dynamic Navigation** and **Scroll Animation Engine**, ensuring that the website feels alive and responsive across all devices—from large desktop monitors to mobile screens.

## ✨ Accurate Features (Verified from Code)

- **Dynamic Sticky Navbar**: The navigation bar adapts its styling (e.g., background transparency and shadows) dynamically when the user scrolls down the page.
- **Scroll Spy (Active Link Highlighting)**: As you scroll through different sections (Home, About, Services, etc.), the navbar automatically highlights the corresponding navigation link.
- **Scroll Reveal Animations**: Elements elegantly fade and slide into view as they enter the viewport, executed via a custom intersection algorithm in vanilla JavaScript.
- **Smooth Anchor Scrolling**: Clicking on any navigation link glides the user to the target section smoothly, accurately offsetting the sticky navbar height to prevent content overlap.
- **Responsive Hamburger Menu**: A fully functional mobile navigation toggle that switches smoothly between 'bars' and 'times' icons, and automatically collapses when a link is clicked.
- **Modern UI Patterns**: Implements glassmorphism (`.glass-card`), CSS grid/flexbox layouts, and floating shape decorations.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure and accessible layout.
- **CSS3**: Custom styling, CSS Variables for theming, Flexbox/Grid for responsive design, and CSS transitions.
- **Vanilla JavaScript (ES6)**: DOM manipulation, scroll event handling, and custom animation triggers without heavy external libraries.
- **FontAwesome 6.4.0**: Scalable vector icons for services and social links.

## 🚀 Setup & Installation

Since this project relies completely on static files, no build step or node package installation is required!

1. **Clone the repository** (if using git):
   ```bash
   git clone <your-repo-url>
   ```
2. **Open the project**:
   Navigate to the project folder and simply open `index.html` in any modern web browser.
3. *(Optional)* **Live Server**:
   For the best development experience, open the folder in VS Code and use the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension.
